 EcoRadar

Environmental Web Platform for Almaty

 About the Project

EcoRadar is a web project about environmental problems in Almaty. It helps users check air quality, find nearby parks and recycling points, and read environmental news.

I started this project because air pollution is a serious problem in Almaty. My goal was to create a website where people could find useful environmental information in one place.

EcoRadar was developed as a team project. My main responsibility was developing the website and its features.

 Main Features

- Air quality map with data from the OpenWeather API.
- Air quality grid showing information across different locations.
- Search for nearby parks and green areas.
- Map of recycling points and waste collection locations.
- Address search and current location detection.
- Basic walking route planning.
- Environmental news with links to original sources.

Technologies

- HTML5

- JavaScript (ES6+)
